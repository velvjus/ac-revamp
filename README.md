# Auto-City — Website Revamp & Design System

A high-fidelity front-end revamp and interactive design system for **Auto-City**.

## 🌟 Key Portals & Entry Points

- **[Showcase & Review Portal](index.html)**: Central hub previewing all revamped templates, landing pages, and interactive features.
- **[Brand Guidelines & Design System](brand-guidelines.html)**: Living design system containing color palettes, typography scales, components, buttons, and design tokens.
- **[Research & Strategy Dossier](research.html)**: Market research, competitive analysis, SEO audits, and content frameworks.

## 📁 Repository Structure

```
Auto-City/
├── index.html              # Central showcase & review portal
├── research.html           # Brand & competitor research, market data & audit findings
├── brand-guidelines.html   # Living design system (colors, typography, UI components)
├── pages/                  # Revamped subpages, flows, and templates
├── components/             # Reusable UI components (headers, footers, cards, modals)
├── css/                    # Shared stylesheets, variables, and responsive design tokens
├── js/                     # Modular JavaScript and micro-interactions
├── Graphic/                # Brand graphics, logos, and reference visuals
└── assets/                 # Supporting icons, illustrations, and media
```

## 🚀 Getting Started

This is a lightweight, dependency-light front-end prototype. You can view and test it directly in any modern browser:

1. **Clone the repository**:
   ```bash
   git clone <YOUR_REPO_URL>
   cd Auto-City
   ```

2. **Run locally**:
   - Open `index.html` directly in your browser, or
   - Use a lightweight static server (e.g. VS Code Live Server or `npx serve .`):
     ```bash
     npx serve .
     ```

## 🛠️ Tech Stack & Standards

- **Core**: Semantic HTML5, modern CSS3 (Flexbox/Grid, CSS Custom Properties, clamp typography), Vanilla JavaScript.
- **Components & Icons**: Lucide Icons, modern slider integrations (Swiper).
- **Standards**: Responsive design (mobile 390px to 1920px desktop), high-contrast accessibility, smooth micro-interactions.
